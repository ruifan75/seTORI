# フロントエンドの一覧

一覧は「1 行が何を表すか」で分ける。歌唱、楽曲、配信、チャンネル、原曲アーティスト、
プレイリストが閲覧用の 6 種類。検索候補、再生キュー、編集・審査、管理の実行記録は
選択や更新の意味が違うため別の操作画面として扱う。

## 配信横断の歌唱一覧（実装済み）

`PerformanceList`、`PerformanceListToolbar`、`PerformanceActions` を使う。
ページが行の JSX を複製せず、`toPerformanceListItem` で表示と再生・追加・報告に渡す値を
一緒に作る。データ取得・権限による絞り込み・並び順・ページングは既存の API が担当する。

| 欄位 | 定義・表示 |
| --- | --- |
| 識別子 | performance ID。選択と再生状態は曲 ID では比較しない |
| 楽曲 | 曲名と原曲アーティスト。別々の詳細リンク |
| 画像 | 曲アートを優先し、無ければ配信サムネイル。曲詳細の履歴は配信サムネイルを優先 |
| 歌唱者 | 実際に歌ったチャンネル。チャンネル詳細では本人だけのとき省略し、合唱時は全員表示 |
| 出典 | 配信名と配信へのリンク。同じ曲の別歌唱を区別する手がかり |
| 日付 | 配信開始日のローカル表示。開始秒を足した歌唱日時とは区別する |
| 開始位置 | 動画内の start_seconds。「〜から」と表示する |
| 長さ | end_seconds − start_seconds。終了が不明／開始以下なら「—」 |
| バージョン | 通常タグとカスタムタグ。秘匿の印も見落とさない位置に残す |
| 操作 | 画像で再生／一時停止、＋でキュー／プレイリストへ追加、⋯で報告と YouTube |

### ページごとの違い

| ページ | 主見出し | 再生範囲・追加操作 |
| --- | --- | --- |
| Channel 歌唱履歴 | 楽曲 | 現在のページ。配信日・曲名・配信名の並び替えは全画面幅で操作できる |
| 曲詳細の歌唱履歴 | 配信 | 現在のページ。親の曲情報を再生・報告にも補完する |
| 歌唱タグ結果 | 楽曲 | 現在のページ |
| 通常／共有プレイリスト | 楽曲 | 取得した全項目。所有者には移動・削除を ⋯ に追加する |
| プリセット | 楽曲 | 取得した項目。全件より少なければ「表示中を再生」と明記する |

再生ボタンを押すと、その行以降を含む表示中の並びをキューに載せる。
現在選択中の同一 performance を押すと、既存キューを保持したまま再生／一時停止を切り替える。
曲名・配信名・歌唱者リンク、＋、⋯ からは行の再生を発火させない。
再生中と一時停止中を区別して表示する。

スマホとデスクトップは同じ DOM の行を使い、長さとメタ情報の配置を変える。
操作は hover せずに見える。⋯ は画面内に収め、外側のクリック・フォーカス移動・Esc で閉じる。
並び替えは表の見出しに依存せず `SortControl` を使う。

## 別の文脈として残すもの

- 配信内セットリスト：そのページの動画へシークする。曲順と時間範囲が主役。
  既存の `StreamPerformanceList` / `PerformanceListRow` を使う。
- ホームの発見用カード：`PerformanceCard` / `PerformanceCardRow`。
- 再生キュー：既存キューの位置を変える操作であり、新しいキューを作らない。
- 編集・審査：草稿、照合結果、未確定の時刻など、公開済み歌唱とは異なる情報を扱う。

## 次に共通化する候補

- 配信カード：ホーム、配信一覧、検索、配信タグ、チャンネルの配信一覧。
- 楽曲目録の行：楽曲一覧、原曲アーティスト詳細。ホームの人気曲はカードとして残す。
- プレイリスト目録のカード：自分／公開／プリセット／フォロー中。
- Channel の「歌った楽曲」：曲ごとに回数と最近の歌唱を集約する別ビュー。
  現在の履歴をブラウザ内だけで集約するとページ外を数えられないため、API の対応後に追加する。
